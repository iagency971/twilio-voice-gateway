# Addendum E — Common complete-session support for causal C1 vs C5 comparison

**Frozen:** 2026-08-26, before any valid C1 H1/H2 reaction result is generated or inspected.

**Scope:** support alignment caused solely by the frozen detector's legacy end-of-file future guard. No reaction outcome has been consulted.

## 1. Outcome-blind implementation fact

The frozen detector source contains the eligibility guard:

`i + HORIZON + REACT_MAX >= N`

with `HORIZON=240` and `REACT_MAX=60` active M1 observations.

This guard exists because the historical detector also computed future reaction/outcome columns. Those columns are excluded from the C1 cadence study, but Section 2 of the parent preregistration freezes the mechanical C1 detector with no source mutation other than cadence, so the guard remains present in the mechanical C1 geometry stream.

On one continuous Aug-2024 through Jul-2026 run, this guard affects only the absolute tail of H2. It does not create an H1/H2 boundary restart.

The frozen OOS C5 location table was generated by an outcome-blind geometry engine that intentionally removed this future-outcome guard and therefore retains end-of-period C5 state support.

## 2. Historical baseline remains full-window

`FROZEN_C5_BASELINE` remains unchanged and is consumed on the full preregistered windows:
- H1 through `<2025-08-01T00:00:00Z`;
- H2 through `<2026-08-01T00:00:00Z`.

Its frozen counts/rates must not be truncated, recalculated, or rewritten.

## 3. Primary causal cadence comparison uses common complete NY sessions

The valid `CAUSAL_ACTIVE_INTERVAL_V1_C1` vs `CAUSAL_ACTIVE_INTERVAL_V1_C5` comparison must use identical complete New York US sessions.

The common endpoint is determined mechanically from raw active-M1 chronology and the frozen detector guard, before reaction outcomes:

1. compute the last active-M1 timestamp eligible under the unchanged mechanical C1 guard (`i < N - (HORIZON + REACT_MAX)`);
2. convert that timestamp to `America/New_York`;
3. include only NY session dates for which the full preregistered 08:00–17:00 NY session is covered by the mechanical C1 support;
4. if the guard cuts through a NY session, exclude that entire final partial session from **both** causal C1 and causal C5;
5. H1 is unaffected unless the same mechanical rule actually cuts an H1 session (it should not in the continuous 24-month chronology).

No date is selected from reaction results.

## 4. Reporting

Each H1/H2 causal result must report:
- original preregistered calendar window;
- common causal support start/end or included NY session-date range;
- any excluded tail NY session dates and the reason `LEGACY_FUTURE_GUARD_COMMON_SUPPORT`;
- contact/trading-day metrics only on the aligned causal support.

Outcome-blind geometry/stability diagnostics may additionally report their native full available state support, but the primary reaction effect size and paired-day bootstrap must use the same complete-session set for C1 and C5.

## 5. Interpretation

This alignment prevents a few hours of extra frozen-C5 tail support from being mistaken for a cadence effect. It does not improve or worsen C1 based on observed reaction outcomes and authorizes no production/Pine change.
